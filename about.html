About the Build

CTRL + FLY

A drone flight data analysis system paired with a cinematic flight simulator — built to show both sides of drone work: the piloting experience and the telemetry underneath it.

Stack

What it's built with

Backend logic

Python

Telemetry parsing, validation and CSV/KML generation.

Data formats

CSV & KML

Tabular flight logs and GPS-mappable flight paths.

Frontend

HTML / CSS / JS

Every simulator zone and research page is a standalone, live page.

Design language

Onboard HUD

Cyan telemetry glow, amber cautions, monospace data readouts throughout.

Structure

How the project is organized

Simulator wing

4 zones × 3 levels

Desert Basin, Metro Skyline, Arctic Ridge and Ocean Platform — each a separate live page with its own environment art, hazard, gate layout and live HUD stats. Level 1–3 changes the altitude band; the chosen airframe changes top speed and ceiling.

Research wing

History + 2 deep dives

A short chronological history of unmanned flight, a gallery of well-known airframes, and detailed specification breakdowns of the ideaForge Q6 mapping drone and the Asteria Aerospace surveillance fleet.
